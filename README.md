# Newport Specialty Partners — Acquisition CRM

Enterprise M&A / acquisition deal-management dashboard for Newport Specialty Partners.

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Lucide React
- Recharts
- React Router

## Getting started

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal (typically `http://localhost:5173`).

## Sprint scope

This release includes the **application shell** and the **main Dashboard** only.

Other navigation destinations are visual placeholders for future sprints.

## Demo data

All opportunity financials and company names are **fictional demo data** for UI prototyping. They do not represent actual Newport information.
